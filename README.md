
# Pythagorean Triples — пифагоровы тройки на Java

Небольшой учебный проект на Java Core для работы с **пифагоровыми тройками** — числами `a`, `b` и `c`, удовлетворяющими равенству `a² + b² = c²`.

Программа работает через аргументы командной строки и поддерживает два режима: **проверку трёх чисел** и **поиск заданного количества троек**.

## Возможности

- Проверка, образуют ли три переданных числа пифагорову тройку.
- Перебор целых положительных чисел от `1` до `999` для поиска троек.
- Вывод найденных троек в консоль.

## Технологии

- Java Core
- Циклы `while` и условные конструкции
- Аргументы командной строки (`String[] args`)
- Арифметические операции и методы

Сторонние библиотеки, Maven и Gradle не используются.

## Запуск

Для запуска нужен JDK. Компиляция и работа проверены на **Java 21**.

Из корневой папки проекта выполните:

```bash
javac -encoding UTF-8 -d out src/PiTri.java
```

**Проверить три числа:**

```bash
java -cp out PiTri 3 4 5
```

Результат:

```text
3, 4, 5 — это настоящая пифагорова тройка!
```

Для чисел, не удовлетворяющих равенству, программа сообщает, что они не образуют пифагорову тройку.

**Найти первые две тройки:**

```bash
java -cp out PiTri 2
```

Результат:

```text
Числа 3, 4, 5 являются пифагоровой тройкой
Числа 4, 3, 5 являются пифагоровой тройкой
```

Если запустить без аргументов, программа выведет подсказку по использованию.

Проверка равенства `a² + b² = c²` вынесена в отдельный метод `checkTriple`.

## Ограничения

Проект отражает начальный этап практики Java и не предназначен для вычислений с большими диапазонами:

- Поиск использует три вложенных цикла `while`, поэтому при большом количестве запрошенных троек может работать очень медленно.
- Перестановки первых двух чисел считаются разными результатами: например, `3, 4, 5` и `4, 3, 5`.
- Для режима проверки трёх чисел нет проверки положительности аргументов.
- При нечисловом аргументе возможно исключение `NumberFormatException`.
- При передаче двух или более трёх аргументов программа завершается без сообщения.
- При больших значениях целых чисел возможны переполнения при вычислении квадратов.
- Автоматические тесты не добавлены.

## Возможные улучшения

- Добавить проверки аргументов командной строки и понятные сообщения об ошибках.
